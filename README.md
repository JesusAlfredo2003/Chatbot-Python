# Python Chatbot
This project is a simple chatbot built in Python. It responds to user input with greetings, jokes, and predefined messages.

## Features
* Handles greetings and basic conversation
* Generates random jokes
* Uses modular structure (separate files)
* Processes user input

## How to run
```bash
python chatbot.py
```

## Technologies
* Python

## What I learned
* Conditional logic
* Modular programming
* User input handling
